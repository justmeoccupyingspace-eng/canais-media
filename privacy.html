Privacy Policy

Last updated: October 16, 2026

canais-dark is a private automation tool operated by a single developer for the YouTube channels that developer owns. It is not offered to the public.

Data accessed

With the developer's own Google account authorization, the app accesses: (1) the developer's own YouTube channels, to upload videos and edit their metadata; (2) YouTube Analytics for those same channels, to read performance metrics; (3) files the app itself creates in the developer's Google Drive (drive.file scope), used as storage for rendered videos.

Use and sharing

This data is used only to operate the developer's own channels. It is not sold, shared with third parties, or used for advertising. The app does not collect personal data from viewers or any other users. Google user data use follows the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

Authorization tokens are stored as encrypted secrets in the developer's private code repository. Analytics are read on demand and not redistributed.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
